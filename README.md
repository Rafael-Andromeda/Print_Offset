Langkah-langkah untuk running aplikasi:

1. lakukan pip install pyinstaller di terminal vscode
2. Jalankan database_ini.py
3. copy teks berikut dan tempel di terminal "pyinstaller --onefile --windowed --name PrintingApp mainBaru.py" (jika mau melakukan exe yang lain ubah nama file pynya)
4. buka file explorer dan masuk ke path penyimpanan filenya
5. copy database.db dan paste ke folder dist
6. run PrintingApp

NOTE : MATIKAN ANTIVIRUS
